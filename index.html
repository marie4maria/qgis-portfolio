// Workflow
01
Data Acquisition
Loaded OpenStreetMap base layer + high-res satellite imagery via QuickMapServices plugin.
02
Digitizing
Created new GeoPackage layer. Digitized 150+ land use polygons across 6 categories (residential, commercial, green space, industrial, water, transport).
03
Attribute Classification
Populated attribute table with land_use, area_m2, and notes fields. Used Field Calculator for area auto-computation.
04
Styling & Cartography
Applied categorized symbology by land_use type. Customized fill colors, outlines, transparency. Designed print layout with legend, scalebar, and north arrow.
05
PyQGIS Automation
Wrote Python script to auto-apply color ramp to new layers and export each category as a separate PNG tile for use in AI training datasets.
pyqgis_export.py — batch layer export snippet
# Load layer and apply categorized renderer
layer = QgsProject.instance().mapLayersByName('land_use')[0]
categories = []

color_map = {
    'residential': '#f4a261',
    'commercial':  '#e76f51',
    'green_space': '#2a9d8f',
    'industrial':  '#264653',
}

for label, color in color_map.items():
    sym = QgsSymbol.defaultSymbol(layer.geometryType())
    sym.setColor(QColor(color))
    cat = QgsRendererCategory(label, sym, label)
    categories.append(cat)

renderer = QgsCategorizedSymbolRenderer('land_use', categories)
layer.setRenderer(renderer)
layer.triggerRepaint()
